# ویترین (Vitrine) — بازار آنلاین خرید و فروش

پروژه‌ی کامل شامل بک‌اند (Node.js + Express + Prisma) و فرانت‌اند (Next.js) برای یک اپلیکیشن آگهی مشابه دیوار، مستقل و با مدیریت مجتبی جرجندی.

## ساختار پروژه

- backend :  سرور API، دیتابیس، احراز هویت، پرداخت
- frontend : رابط کاربری Next.js
- docs :     راهنمای استقرار و تنظیم سرویس‌ها

## اجرای محلی

مرحله ۱ - بک‌اند: وارد پوشه‌ی backend شوید، فایل .env.example را به .env تغییر نام دهید، دستور npm install را بزنید، سپس npx prisma migrate dev --name init و در پایان npm run dev را اجرا کنید. سرور روی پورت 4000 بالا می‌آید.

مرحله ۲ - فرانت‌اند: در یک ترمینال جدید وارد پوشه‌ی frontend شوید، فایل .env.example را به .env.local تغییر نام دهید، دستور npm install را بزنید، سپس npm run dev را اجرا کنید. سایت روی پورت 3000 بالا می‌آید.

سپس مرورگر را باز کنید: http://localhost:3000

## تست ورود بدون سرویس پیامک واقعی

اگر KAVENEGAR_API_KEY را در فایل .env خالی بگذارید، کد تایید ۴ رقمی در کنسول ترمینال بک‌اند چاپ می‌شود.

## ورود به‌عنوان مدیر

با شماره‌ی موجود در ADMIN_PHONE (پیش‌فرض 09120000000) وارد شوید تا نقش مدیر فعال شود.

## چیزهایی که قبل از پروداکشن باید خودتان انجام دهید

1. سرویس پیامک واقعی مثل کاوه‌نگار یا قاصدک
2. درگاه پرداخت بین‌بانکی واقعی مثل زرین‌پال، متصل به شاپرک
3. دیتابیس Postgres واقعی برای پروداکشن
4. هاست یا سرور واقعی برای بک‌اند و فرانت‌اند
5. ثبت دامنه برای اپلیکیشن

## فناوری‌های استفاده‌شده

بک‌اند: Node.js, Express, Prisma ORM, JWT
دیتابیس: SQLite برای توسعه، PostgreSQL برای پروداکشن
فرانت‌اند: Next.js, React, lucide-react
پرداخت: زرین‌پال، قابل تعویض با هر درگاه دیگر
پیامک: کاوه‌نگار، قابل تعویض با هر سرویس دیگر
